# Омск в Blender

Откройте `omsk.blend` в Blender 4.3 или новее. В списке сцен доступны обзор Омска, крупный план центра и юго-востока, отдельные виды Центра, Чкаловска, Рабочих и Старой Московки, а также модель высот Copernicus. Все четыре названия на обзорных видах обозначены точками-ориентирами. «Рабочие» относится к кварталам Рабочих улиц, ориентир расположен у 10-й Рабочей.

## Состав карты

- 180 519 контуров зданий и частей зданий из OpenStreetMap. Высота взята из `height` для 80 объектов и рассчитана по `building:levels` для 13 606 объектов. Для 166 876 контуров высота оценена по назначению или размеру здания.
- 62 595 участков дорог, включая улицы, проезды, мосты и пешеходные пути. Ширина берётся из исходных тегов при наличии или подбирается по классу дороги. Подземные участки сохранены в GeoJSON.
- Железные дороги, трамвайные пути, территориальные границы, Иртыш, Омь, водоёмы, парки, лес, поля, аэродромы и подписанные точки интереса. Слои границ и точек интереса можно включить для рендера через Outliner.
- Цифровая модель поверхности Copernicus GLO-30. Высоты сохранены в метрах в отдельной сцене и атрибуте `height_m`. Сетка модели пересчитана с шагом около 60 м. Сцены города используют плоскую картографическую подложку.

Прямоугольник выгрузки охватывает Омск и ближайшие окрестности от 73,15° до 73,64° в. д. и от 54,82° до 55,17° с. ш. Проекция сцены — WGS 84 / UTM zone 43N (EPSG:32643). Одна единица Blender равна одному метру в плане. Чтобы восстановить полные координаты UTM, прибавьте к X и Y значения `UTM_origin_easting` и `UTM_origin_northing` из свойств сцены.

Геометрия разделена по типам и по квадратам размером 2,3 км для зданий, дорог и точек интереса. При редактировании можно навести курсор на отдельную часть объекта и нажать **L**, чтобы выделить связанный участок меша. Для граней доступен ID OpenStreetMap в атрибуте `osm_id`, если ID помещается в 32-битное целое. `osm_type` кодирует узел, линию или отношение числами 1, 2 и 3. Полные идентификаторы, теги и имена объектов доступны в `omsk.geojson.gz`.

## Повторная сборка

В папке проекта запустите Blender из терминала.

```sh
blender -b -P omsk_blender.py -- --out omsk.blend
```

Для выгрузки обзорного рендера, рендера юго-востока, четырёх районов и высотной карты используйте параметры `--render`, `--detail`, `--district-dir` и `--relief`.

Скрипт `omsk_extract.py` извлекает слои из файла OSM PBF в GeoJSON. Ему требуется Python с привязками GDAL и драйвером OSM.

```sh
python3 omsk_extract.py omsk_oblast-latest.osm.pbf omsk.geojson.gz \
  --bbox 73.15 54.82 73.64 55.17
```
